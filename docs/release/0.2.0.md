# Helios 0.2 browser preview

[Open Helios in your browser](https://helios-cad-wasm.yuechenli.chatgpt.site/).
Models run on your device. Use **Save workspace** to keep a STEP file and the
Firmament edits together.

- Import supported STEP solids and multibody files.
- Pick an original edge or face rim on a supported imported solid, then
  preview and apply a fillet or chamfer in **Graph**.
- Inspect the Aetheris version, commit, and runtime type in the workspace
  status bar.

The imported finish workflow supports straight outside edges, whole circular
rims, and convex planar rims with perpendicular sides. Helios asks before
excluding source annotations from a topology edit. Fresh hole placement is
available on authored bodies. Assemblies with explicit surface-only
components may be refused. For a supported source that needs a larger STEP
export budget, set `importTolerance` explicitly in Firmament based on the
file's declared accuracy.

The interface is still early. [Report a problem](https://github.com/yuechen-li-dev/HeliosCAD/issues/new)
with the operation and a small shareable model if you have one.
