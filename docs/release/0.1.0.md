# Aetheris Helios 0.1.0

Aetheris Helios is a local CAD workspace for designing parts with visual tools
or Firmament code, inspecting exact geometry, and exporting engineering and
presentation files. This first release includes the Windows x64 portable app.

## Start

1. Download **Helios-0.1.0-win-x64.zip** from the assets below.
2. Extract the **entire archive**, then run **Helios.exe** inside the extracted folder.
3. Choose **New part**, a gallery example, or **Learn** for the guided tutorials.

The app opens your existing browser. Modeling needs no .NET or Node installation,
cloud account, API key, or AI subscription. A modern Chrome or Edge browser is
recommended. Save your work before choosing **Quit Helios**; closing the browser
tab alone leaves the local host running. Stop an older Helios host before starting
this version. Local project data remains outside the extracted application folder.

## Included

- IntelliDraft for drawing, dimensioning, moving and tracing profiles, then
  extruding them into parts. Curved-outline tracing works in the production AOT runtime.
- Graph controls for supported bodies, holes, pockets, edge finishes, parameters
  and explicit assembly mates, with previews and recovery from rejected edits.
- Firmament source editing with completion, highlighting, diagnostics,
  navigation and formatting, backed by the Aetheris language service.
- Searchable offline Firmament documentation and six guided lessons.
- STEP import and supported semantic annotations, including the SolidWorks
  AP214 -> Helios annotations -> enriched AP242 / annotated GLB workflow.
- STEP, GLB, USDA, STL, OBJ and PDF/SVG/PPTX drawing exports where supported by
  the compiled model. Optional local AI connections have separate client setup.

## Scope and verification

Windows x64 is the packaged platform for this release. This portable build is
unsigned and has no installer or automatic updater; Windows may show a SmartScreen
notice. Keep every companion file beside the executable. Some advanced geometry,
annotation and drawing combinations remain unsupported and report diagnostics.
Saved local projects hold one source document; use **Save workspace** for projects
with includes or imported assets. Inspect drawings before using them for manufacture.

The release is qualified through the extracted self-contained host and production
AOT browser runtime: 62 browser usage tests, including 128 curved traces in both
pick orders, alongside 244 Helios unit tests. The Aetheris full solution passed
6,404 tests with two existing external-renderer tests skipped. Startup/authentication,
exports, project persistence, restart, checkpoints and the local MCP bridge are
covered. Live external AI accounts and a fresh SolidWorks add-in UI session were
not part of release qualification.

**SHA256SUMS** verifies the Windows ZIP. **QUALIFICATION-win-x64.json** records the
package source revisions and checks. The app's **Learn** button and the
[getting-started guide](https://github.com/yuechen-li-dev/HeliosCAD/blob/v0.1.0/docs/public/standalone.md)
cover everyday use. Report problems through
[GitHub issues](https://github.com/yuechen-li-dev/HeliosCAD/issues), with the diagnostic
and a small reproducible model when possible.
